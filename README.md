# After Effects Mobile

A native C++ Android editing-interface prototype inspired by the desktop After Effects workflow.

## First milestone

- Dark project home screen
- Composition workspace and preview panel
- Timeline with layers and a movable playhead
- Contextual editing toolbar

## Technology

- C++17 application and UI
- Android NDK NativeActivity
- OpenGL ES 3
- Dear ImGui for the touch-friendly interface
- CMake and Gradle for Android builds

This is an original mobile interface prototype, not Adobe software. Adobe names and marks belong to Adobe.

## Build

Open the project in Android Studio with Android SDK, NDK 27.0.12077973, and CMake 3.22.1 installed, or run the `Android APK` GitHub Actions workflow.
